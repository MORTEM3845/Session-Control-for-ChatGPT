# Session Control for ChatGPT

Неофициальное расширение Chrome для работы с несколькими параллельными чатами ChatGPT из одной боковой панели.

> Проект не связан с OpenAI и не одобрен OpenAI. ChatGPT является товарным знаком OpenAI.

## Возможности

- список всех открытых вкладок ChatGPT;
- статусы «размышляет», «использует инструменты», «формирует ответ», «готово», «ошибка»;
- отметка готовых, но ещё не просмотренных ответов;
- локальное переименование чатов без изменения названия на сервере;
- переход к нужному чату одним кликом;
- системные уведомления и счётчик непрочитанных ответов;
- отображение модели или режима, если он виден в интерфейсе;
- приблизительная оценка объёма видимого контекста;
- поиск, фильтры и группировка вкладок;
- безопасное закрытие дубликатов с предварительным подтверждением;
- горячая клавиша `Ctrl+Shift+U` для следующего непрочитанного ответа.

## Приватность

Расширение не использует сервер, аналитику, cookies, API-ключи и сетевую отправку переписок. Данные хранятся только в `chrome.storage.local`.

Сохранение фрагментов последнего запроса и ответа **выключено по умолчанию**. При выключении настройки ранее сохранённые фрагменты удаляются. Полная политика описана в [PRIVACY.md](PRIVACY.md).

## Установка для разработки

1. Скачайте репозиторий или архив исходников.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `extension`.
6. Закрепите расширение и нажмите его иконку.

## Установщик Windows

Установщик кладёт файлы расширения в постоянную папку и открывает страницу расширений Chrome. Из-за ограничений Chrome последнее подтверждение «Загрузить распакованное расширение» выполняется вручную.

Готовые ZIP и EXE собираются автоматически при публикации тега вида `v0.2.0` и прикладываются к GitHub Release.

## Ограничения

Расширение работает по видимому DOM ChatGPT, а не по внутреннему API:

- точный остаток токенов недоступен — показывается оценка по видимому тексту;
- фактическая backend-модель может отличаться от подписи в интерфейсе;
- процент выполнения задачи недоступен;
- после крупных изменений интерфейса ChatGPT селекторы могут потребовать обновления.

## Разработка

Требуется Node.js 20+ только для локальных проверок:

```bash
npm test
```

Проверка валидирует `manifest.json`, необходимые файлы, отсутствие опасных конструкций и синтаксис JavaScript.
