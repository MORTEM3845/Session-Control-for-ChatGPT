# Участие в разработке

1. Создайте fork и отдельную ветку.
2. Не добавляйте зависимости без необходимости.
3. Не добавляйте сетевую телеметрию и расширенные разрешения без отдельного обсуждения.
4. Выполните `npm test`.
5. В pull request опишите изменения, влияние на приватность и проверенные сценарии.

## Стиль

- обычный JavaScript без сборщика;
- Manifest V3;
- интерфейс должен работать без внешних CDN;
- данные пользователя экранируются перед вставкой в HTML;
- фоновые проверки не должны постоянно сканировать весь DOM скрытых вкладок.
