# Changelog

## [0.2.0] — 2026-08-04

### Добавлено

- публичная структура проекта, CI, документация и MIT License;
- воспроизводимый Windows-установщик через Inno Setup;
- подтверждение перед закрытием дублирующихся вкладок;
- настройка локального сохранения фрагментов сообщений.

### Изменено

- продукт переименован в `Session Control for ChatGPT`;
- сохранение фрагментов сообщений выключено по умолчанию;
- запрос вкладок ограничен только доменами ChatGPT;
- удалены избыточные разрешения `tabs` и `windows`;
- наблюдение за DOM ограничено рабочей областью `main`;
- интервалы оценки контекста и фонового heartbeat снижены для меньшей нагрузки.

## [0.1.0] — 2026-08-04

- первый рабочий прототип боковой панели.
